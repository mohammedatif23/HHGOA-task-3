# HH Goa Task 3 — Face ID + Blockchain Verification

An end-to-end prototype for:

Face Identification → Web/Social Media Search → Content Fingerprinting → Blockchain Verification

## Status

🚧 In Development

## Planned Pipeline

1. Detect and encode a face from an input image
2. Perform a genuine web/social-media search
3. Identify a matching post
4. Generate a SHA-256 fingerprint
5. Record the fingerprint on a blockchain
6. Re-verify the content against the on-chain fingerprint
7. Demonstrate tamper detection

## Tech Stack

- Python 3.11
- OpenCV
- face_recognition
- SHA-256
- Blockchain
